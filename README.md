# UVG RPG MOD · Tour virtual del campus UVG en Minecraft

Proyecto de CC2006 Programación Orientada a Objetos (Semestre II 2026), Universidad del Valle de Guatemala.
Dos mods para Minecraft Java 1.21.1 con NeoForge y Java 21.

- `mods/university-guide`: guía permanente, paradas, barreras de exclusión y pantallas del recorrido.
- `mods/posted-signage`: señalización, puertas, vidrios y herramientas de construcción.
- `herramientas`: scripts de compilación y comprobación.
- `pruebas`: registro de resultados de las pruebas automáticas.

## Compilación
Con Java 21, desde la raíz, en PowerShell:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File herramientas/compilar.ps1
```
